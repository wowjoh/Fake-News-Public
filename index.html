1) 언어 형식으로서의 문제 판단

  1. '의혹이 제기되고 있다.' 같이 주체가 없는 표현들을 사용해 문제를 드러내고 있나요?

  2. 언제, 어디서, 누가, 무엇을 했는지 중요한 정보가 빠져 있나요?

  3. 대상에 대한 중립적이지 않은 편향된 관점이 들어간 어휘로 이름을 지었나요?

  4. 사실 설명이 아니라 비유나 과장된 표현으로 감정을 자극하고 있나요?

  5. 제목과 실제 내용이 다른가요?

2) 내용과 사용자 심리와 관련된 문제 판단

  1. 단지 본인 생각과 같아서 믿게 되었나요?

  2. 이 내용을 보고 화나거나 놀라는 감정이 들어서 더 믿게 되었나요?

  3. 여러 번 봐서 익숙함 때문에 진실처럼 여기고 있나요?

  4. '좋아요'나 동의하는 댓글 수가 많아서 믿고 있나요?

  5. 이 글을 믿게됨으로써 특정 집단이 이득을 볼 것 같나요?
